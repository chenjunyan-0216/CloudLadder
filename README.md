# 云梯 CloudLadder Pro

一个 Windows 桌面学习追踪工具(learning tracker),为个人的"云原生运维 6 个月自学计划"配套开发:
把计划拆成每天可执行的任务,用打卡、周考、番茄钟和可视化数据管理学习节奏。

> ⚠️ 非生产级软件(non-production):仅用于个人学习管理,不承诺任何稳定性或数据安全,请自行备份数据。

## 功能列表

- **每日任务 + 收工打卡**:计划逐日拆分,完成任务后在同一张卡里提交打卡(主线/副线/验收三勾 + 可选备注),自动联动与统计
- **可变计划时长**:同一份 24 周母版,按 24 / 12 / 8 / 6 周等比压缩,任务量与题量随节奏等比变化
- **周考 + 错题重测闭环**:120 道题(单选/判断/填空/场景评分点简答四种题型),选择、判断、填空自动判分,做错的自动进错题本,重考答对自动移出
- **面试复盘**:每场面试 24 小时内记录被问倒的题,一键送错题本
- **学习日历 / 热力图 / 周考趋势图**:24 周总览网格、最近 30 天打卡热力图、周考得分折线
- **每日面试题**:主页按日期从题库轮换展示一道面试题
- **打卡提醒**:托盘常驻,到达设定时间(默认 21:00,可在设置调整)当天未打卡则弹气泡
- **昨日漏卡横幅**:漏打卡的次日主页提示,支持内联补记(补记留档但连续天数照断)
- **内置 PDF 阅读器**:基于 PyMuPDF,阅读进度逐页落盘
- **番茄钟**:专注计时记录到 focus_log.csv,完成后页面内 Toast 提示打卡,侧栏常驻显示倒计时
- **速查库**:18 节运维速查内容,支持实时搜索
- **学习记录一键导出**:打卡 + 每周总结 + 错题本拼成 Markdown;周次自动换算为实际日期,换计划后数据不错乱
- **数据备份与恢复**:一键打包全部数据文件(zip + manifest 校验),恢复前自动安全备份,每 7 天自动备份
- **学习统计页**:累计打卡/连续天数/累计专注/日均专注汇总卡,最近 90 天打卡热力图,最近 14 天专注时长柱状图
- **错题间隔复习**:错题按 1/3/7 天间隔重复排期(进度存于错题条目,随备份走),打开错题本一键复习到期题
- **托盘快速打卡**:托盘右键一键记当日打卡并勾选今日任务,无需打开窗口
- **投递漏斗**:投递记录页自动聚合 投递→已读→约面→Offer 四级转化率
- **主题**:19 套完整配色(11 暗 8 浅),点击即时生效;设置页含制作人说明与免责声明
- **界面**:Segoe MDL2 单色图标体系、自绘分段控件与卡片描边,页面缓存切换瞬时响应
- **系统托盘**:关闭窗口最小化到托盘

## 运行方式

从本仓库 [Releases](../../releases) 页面下载安装程序（或绿色版 zip）直接使用：

1. 运行 `CloudLadderPro-Setup.exe`，默认安装到第一个可用数据盘的 `\CloudLadderPro`；
2. 绿色版解压 `软件/CloudLadderPro.zip` 后运行 `CloudLadderPro.exe`；
3. 首次启动在程序同目录自动生成数据文件（题库、计划、速查库等）。

## 已知限制

- 仅支持 Windows 10/11,未适配其他平台
- 数据为单人单机:全部明文存放在程序同目录(JSON/CSV),无云同步、无加密、无多用户
- 打卡/勾选记录按"周次"存储:切换计划时长或修改开始日期后,历史勾选可能与新计划错位;可用「导出学习记录」存档——导出文件已把周次换算为实际日期
- 内置 PDF 需手动放置到 `resources/`(来源为官方免费授权书籍,见下方链接)
- 测试以开发者自测钩子为主,没有系统性自动化测试覆盖
- 代码为单文件结构(app.py),未做模块化拆分

## 目录结构说明

```text
app.py                  # 全部程序代码(单文件)
exam_bank.json          # 周考题库(独立数据文件,可自行编辑增补;缺失时自动重建)
requirements.txt
README.md
.gitignore
resources/              # 内置 PDF(不入库,见 .gitignore)
plan.json               # 24 周计划母版(首次启动自动生成)
config.json             # 开始日期 / 计划时长 / 主题 / 提醒时间等偏好
progress.json           # 每日任务勾选进度
study_log.csv           # 打卡记录
focus_log.csv           # 番茄钟记录
exam_log.json           # 周考成绩
wrongbook.json          # 错题本
reviews.json            # 面试复盘
applications.json       # 投递记录
summaries.json          # 每周学习总结
reading.json            # 阅读进度
backups/                # 自动备份与恢复前安全备份
dist/                   # PyInstaller 打包产物(不入库)
build/                  # 打包辅助脚本与中间产物(不入库)
```

除 app.py 与 exam_bank.json 外的数据文件均由程序在运行时自动创建;`dist/`、`build/` 与个人数据文件均不应提交到仓库(见 `.gitignore` 与《仓库整理说明.md》)。
